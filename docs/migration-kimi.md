# 升级到 v0.6.1 Kimi 接入版

研究算法、实验规模、开发池和最终评价协议保持 v0.6 的定义。本版新增实验室模型发现与连接配置，属于接入功能修改，不是纯排版版本。

源码字节、Python 版本号以及 ModelConfig 的连接字段改变，因此框架源码哈希和合同哈希会变化。不要覆盖正在运行的旧代码，也不要手工替换旧哈希。

解压到独立目录后启动新研究：

```bash
bash start.sh --root "$HOME/arlab-kimi"
```

旧研究继续使用旧源码、旧模型和原目录。新版学生默认只填写 `NEW_API_KEY`；旧 `ARLAB_API_KEY` 仅作兼容回退。密钥没有被写入模型设置或安装配置。

文档中的三任务开发、九任务最终、高预算、续训和恢复规则仍有效。此前的 readability 等价证明是历史记录，不是说本次接入修改也 AST 一致。

更换名称或输出目录不能消除已看过最终成绩这一研究事实。
