# v0.5.1 Review：探索同时覆盖三种环境与三种数据分布

这是一次针对研究协议的源码自审与回归，不是外部审计，不是算法性能评价。当前验收结果见 `../evidence/validation.json`；旧版结果单独存于 `../evidence/history-v0.5/`。

固定探索 ID 为 halfcheetah-medium-v2、hopper-medium-replay-v2、walker2d-medium-expert-v2。三种环境各选一种不同数据构造；不是每个环境都用 medium。最终仍评价完整九项，同方法同配置按任务重新训练。

## 研究解释边界

三个探索任务同时覆盖环境与数据分布，但这两个因素在该子集中是混杂的。任务配对预先固定，不通过搜索得分挑选。三个探索分数既不能证明因果归因，也不保证覆盖所有实际情况。全九项用于观察所有组合；六项只标为“未用于本次搜索”，不宣称完全未知环境或分布。

同档、同种子的完整面板决定可比性；候选是否具有普遍收益仍需独立证据。最后一档完整也允许保留负结果，不强迫 Agent 找到胜过 IQL 的方法。

## 验收类型

`tests/test_classroom.py` 新增 16 个参数化测试用例；其中账本、评分替身使用明确标注的合成数据。原有真实单任务→九任务集成测试改为真实三任务→九任务：CPU IQL、每项两个更新、开发一个种子，最终一个新种子，保留 baseline。它验证控制流，不是三种 D4RL 分布的性能测试。

已检查源码语法、预览入口、安装后 Wheel 的三分布协议生成、源码与 Wheel 一致性。全套回归包含开放候选、调研、上下文、权限、恢复与部署故障测试。最初的整套调用因工具命令时限中断，随后在源码固定后重跑并保留两次日志；最终状态以 tests.xml 为准。

真实 D4RL 数据下载、MuJoCo 编译、GPU/Docker、在线文献服务和模型服务，本环境未完成新的在线验收。不能把单元测试的合法任务 ID、合成世界或 HTTP 测试替身当成真实 benchmark 成绩。没有宣称任何性能提升。

## 迁移

不修改旧实验身份、不改写旧最终成绩。新协议使用新源码目录及部署根目录；详见 `migration-0.5.1.md`。`start.sh` 的学生交互方式保持不变，无需新增密钥或逐项配置任务。
