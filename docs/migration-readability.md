# 使用阅读整理版与已有运行

本包保留 Python 版本号 `0.6.0`，没有修改研究协议、默认预算、接口、提示、测试或算法。它是源码阅读与文档整理版，不是新的算法版本。

## 为什么仍不能覆盖正在运行的目录

`core/io.py:source_digest()` 按包内 Python 文件的**原始字节**计算实现身份，现有部署、实验与检查点会绑定该身份。注释、换行、引号排版和堆栈行号变化也会改变原始源码哈希。

因此，“可执行语法树一致”不等于“原有缓存和检查点身份不变”。本次没有修改哈希函数、放宽完整性检查或伪装成原实现。

## 两种安全使用方式

已有 v0.6 研究还要继续运行：保留原源码、原环境和原账本，继续使用原版；把本整理版作为独立阅读副本。

开始新的研究：解压到新目录，默认部署根目录随源码目录变化；使用自定义根目录时，明确换一个新的 `--root`，例如：

```bash
bash start.sh --root "$HOME/arlab-readable"
```

不要手动修改旧的 source hash、冻结文件或数据回执来绕过校验。新目录也不能让已用于调优的最终成绩重新变成独立测试信息。

## 包与证据的命名

源码 ZIP 带 `readability` 后缀便于区分；运行包元数据仍为 0.6.0，避免在非逻辑改动中修改默认返回值。新验收记录位于 `evidence/validation.json`；原 v0.6 的记录保留在 `evidence/history-v0.6.0/`。运行结果中的实现哈希可能不同，提示、语义输出字段和研究规则保持不变。
