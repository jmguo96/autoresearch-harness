# 从 v0.6.1 迁移到 v0.6.2 uv-local

本版改变的是依赖安装、运行环境、执行方式和版本身份，不改变 IQL 数学、研究提示、
三分布开发与九任务最终评价、预算、检查点语义或资料调研协议。

请解压到新的源码目录，直接运行 `bash start.sh`。默认管理目录为源码下的
`.arlab/d4rl9`；高级 `--root` 也必须位于该源码目录，不能指向家目录或其他项目。
使用大磁盘时把整个源码目录放在那里，再建立新部署。

**不要把 v0.6.1 原有运行原地改成 v0.6.2。** 源码哈希、运行环境和执行策略已变化，
原实验及检查点仍使用原代码恢复。本版不自动导入旧账本、修改 source hash 或重用
旧的 Docker 运行声明。科学协议内容相同也不等于身份可静默替换。

已下载 HDF5 可以通过低层部署 `--raw-dir` 显式作为只读输入。它在外部只是用户已有
资料，本安装器产生的转换结果、下载和缓存继续写入新项目；不会搬动或改写旧数据。

默认执行模式现在是已授权本地 Python。uv 虚拟环境不保护宿主文件权限；研究启动
会说明这一点，模型仍只能通过既有工具修改候选，不因此获得 sudo 或安装工具。
任意候选 Python 的真实访问能力仍取决于执行账号，不能作出操作系统沙箱保证。

安装缺少系统 C/OpenMP、GL/OSMesa 时会停止。可先让首次预检建立失败状态和日志，
然后由教师把已审核且 ABI 匹配的依赖放到新根目录的 native 子目录后重复命令，或
使用已具备系统库的课程 Linux 主机。脚本不会自动安装系统包、切换 benchmark。

安装器以前曾经产生的系统包或全局 Docker 镜像不由本版自动卸载，以免影响其他项目。
删除或归档旧项目之前先保留其研究结果；本版不提供全局清理命令。
