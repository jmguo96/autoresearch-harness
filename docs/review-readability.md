# v0.6 教材阅读整理：变更范围与核对

这是一轮代码阅读与文档整理，不是功能升级，也不是新增研究逻辑修复。Python 包版本仍为 `0.6.0`。原版修复的历史记录见 [review-v0.6.md](review-v0.6.md)，本轮证据见 [validation.json](../evidence/validation.json)。

## 1. 什么发生了变化

包内七个文件增加了面向阅读的注释，部分长参数和结果字典按字段展开：

| 文件（相对 src/arlab） | 阅读重点 |
|---|---|
| `core/harness.py` | 初始化、模型决策、工具分派与五段循环 |
| `core/context.py` | 身份选择、事实摘要、视图组装和裁剪 |
| `core/capabilities.py` | 菜单、动作 schema 和授权共用能力视图 |
| `core/experiments.py` | 请求检查、身份、复用、续训、预留、执行、提交 |
| `core/checkpoints.py` | 训练轨迹与观察端点的不同身份 |
| `audit.py` | 最终条件固定、方法去重、恢复池 |
| `classroom/session.py` | 开发研究与最终审计的衔接 |

没有移动模块、重命名函数、提取新的执行函数、重排条件或修改异常捕获；导入与调用顺序保留。没有改变模型提示、工具返回字符串的值、数据结构或验证条件。原 docstring 和类型注释也纳入语法树比较。

新增的 `scripts/verify_readability.py` 是用户手动运行的标准库核对工具，不被 Agent 调用，不进入研究主循环。

## 2. 文档一致性修正

架构、驱动范例、上下文、快速开始按 v0.6 重写或合并，去除“旧版说明＋末尾追加新版”的混杂呈现。新增文档目录、源码阅读指南和术语表，第一遍围绕少量现有函数阅读。

| 原先容易误读的说明 | 现在的准确范围 |
|---|---|
| 单任务就是整个探索协议 | 三任务开发池内可先做单任务试探，冻结前补齐完整开发对照 |
| 每一档都从头训练，不支持续训 | 自适应模式固定完整日程，兼容累计端点实际续训 |
| 每次正式实验都必须全三任务三 seed | 局部实验可指导研究，完整性要求落在确认与冻结 |
| 最多四个候选版本 | 128 个活跃方向与 10,000 份修订分开，仍受其它预算约束 |
| 安装器低层默认就是教材主协议 | `start.sh` 是完整主入口，单环境／suite12 是仍保留的低层选项 |
| 论文调研默认关闭或需要 Brave Key | 学生入口启用免额外搜索 Key 的论文/公开代码调研，通用搜索关闭 |
| 开发结束就是最终结果 | `finish` 固定方法，入口随后运行九任务确认 |
| 全九项平均提高即可无范围地声称改善 | 保留全九项描述性结果和未用于搜索任务的证据区分 |

参考来源文件中的旧续训表述也已按现有代码修正，原外部链接和原核对日期保留；本轮没有重新检索网站。历史 README、Review 和迁移记录标成历史材料，不把旧测试数当成本轮验收。

## 3. 未改变的行为资产

既有 **94 个 Python 文件**（其中 **70 个包内运行文件**）的 AST 全部一致，比较忽略行列位置，但包含常量、docstring、参数、注解和类型注释。包内只有上述七个文件的字节改变。

另对 **81 个受保护文件**做字节核对，覆盖原测试、示例、JSON 配置、依赖/容器/启动资产，以及算法、任务、模板、技能、调研、部署等关键资产；不包含作为人类文档修改的 `configs/README.md`。原 14 个测试文件没有修改断言。

没有修改三分布开发池、九任务面板、确认 seed、训练上限、预算、调研权限、固定 IQL、in-sample 边界或模型系统提示。默认值/接口快照核对见当前 evidence。

## 5. 旧运行与复现

```bash
python scripts/verify_readability.py \
  --baseline /path/to/autoresearch-agent-v0.6.0.zip
pytest -q
```

核对脚本读取原 ZIP，不导入其中代码，不需要网络或密钥。原始 ZIP 请另外保留。

源码原始字节参与现有实验身份，所以不要替换正在运行的 v0.6 或直接续跑旧账本。本包保留该检查，详见[使用已有运行](migration-readability.md)。即使 AST 相同，也不能手工改哈希绕过保护。

本次未完成新的真实模型自主研究、D4RL 三任务探索与九任务确认、legacy MuJoCo 编译、CUDA、Docker 或在线资料验收。没有由此宣称算法、模型自主性、教学效果或运行性能提升。原用户教材章节未被修改；本包只整理它所配套的仓库代码与说明。
