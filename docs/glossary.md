# 术语表：研究组织、训练状态与证据分开

| 术语／代码名 | 本项目的含义 | 容易混淆的地方 |
|---|---|---|
| 完整研究／study | 学生入口衔接开发 Campaign 与最终确认 | 开发 `completed` 不代表完整研究已确认 |
| 开发研究／Campaign | 在预授权任务池中调研、修改和选择方法 | 不是一个训练作业，也不是最终九任务审计 |
| 研究合同／`ResearchContract` | 目标、数据、种子、资源、权限与最终要求 | 不是研究者可以随结果改写的计划 |
| 研究方向／branch | 组织同一方向的修订并记录活跃／归档状态 | 修一个 bug 不必占新方向名额 |
| 候选／candidate | 一份不可变配方或源码与配置修订 | 新版本不是自动证明新假设或性能提高 |
| 训练轨迹／series | 固定算法、数据、seed、训练日程和请求执行条件下的连续训练 | 换代码、seed 或数据不能继承不兼容状态 |
| 累计端点／steps | 该次请求希望达到的累计更新位置 | 5,000→20,000 增加 15,000，不是再加 20,000 |
| 训练日程／`schedule_steps` | 初始化调度器和算法时所知的完整训练长度 | 不随每次暂停端点重新衰减到零 |
| 实验记录／trial | 候选×任务×seed×端点×评价条件的一次观察 | 一个轨迹可以有多个端点；不是多个独立 seed |
| 执行尝试／attempt | 执行或恢复某个请求的一次资源预留与运行 | 同一 trial 失败重试仍会消耗额度 |
| 实现检查／`purpose=check` | 小规模真实训练、导出和评价的接口检查 | 不能填进正式排名或完成条件 |
| 训练档位／rung | 合同给出的参考端点与完整面板汇总位置 | 自适应模式允许区间内其它端点，不强制逐档遍历 |
| 面板／panel | 指定任务、seed、端点和评价条件的实验集合 | 局部集合完整不等于整个合同完整 |
| 训练种子／train seed | 独立初始化与训练随机状态 | 增加评价 episodes 不会增加训练 seed |
| 评价 episode | 一次完整环境 rollout | 同一策略多次 rollout 与重新训练不同 |
| 训练 tick／update | 算法调度的一次循环计数 | 不同算法每 tick 优化器步数或算力可不同 |
| 上下文／context | 本轮模型能直接看到的有限信息视图 | 不是全部可访问材料或全部持久状态 |
| 研究记忆／memory | 带来源的观察、假设、经验或决策笔记 | 模型解释不覆盖实验事实，不自动变成已验证结论 |
| source／span | 资料快照与实际读取的具体范围 | 搜索线索不是全文，引用存在不是解释正确性证明 |
| 冻结／finish | 在完整开发对照后固定一个方法 | 冻结不是保证改善，也不是冻结某个任务上的权重 |
| 最终审计／audit | 用户授权的独立面板重训与评价 | 不是研究者随时调用的调参工具 |
| Harness／驾驭系统 | 组织运行循环、权限与状态的稳定执行层 | 不等于基础模型，不是额外元智能体或 RSI |

## 一个连续例子

一个方向先有候选 `c1`。它在某开发任务、seed 0、固定百万步日程下训练到 5,000 步，得到一个 trial。继续到 20,000 步属于同一轨迹的新端点。只增加评价 episodes 复用该端点策略；修改源码形成 `c2`，仍可属于同方向，但要开始兼容性不同的新训练轨迹。加入第二个任务或 seed 1 也产生新的训练。

以上是身份与资源语义，不是实际实验成绩。完整性与数据范围见[研究协议](nine-task-study.md)。
